# Student Marks Calculator

A beginner-friendly student project built with **HTML, CSS, and JavaScript**. Enter a student's details and marks in five subjects to calculate total marks, percentage, grade, and pass/fail status.

## Features

- Student name and roll number inputs
- Five subject mark fields (0–100)
- Total marks out of 500
- Percentage calculation
- Grade calculation
- Pass/fail status (35 marks required in every subject)
- Input validation
- Clear form and print result
- Responsive layout for mobile and desktop

## Grade rules

The student must score at least 35 in every subject to pass.

| Percentage | Grade |
| --- | --- |
| 90–100% | A+ |
| 80–89.99% | A |
| 70–79.99% | B |
| 60–69.99% | C |
| 50–59.99% | D |
| 35–49.99% | E |
| Below 35% in any subject | F (Fail) |

These are example grading rules for this project. Change them in `script.js` to match your institution's rules.

## How to run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter the student details and marks.
4. Click **Calculate Result**.

No installation or extra libraries are required.
